# 🧠 Mental Health in Tech Survey

An exploratory data analysis and interactive Streamlit dashboard project based on a mental health survey conducted among employees in the technology sector.

## 🌐 Live Dashboard

👉 **[View Live Streamlit Dashboard](https://mental-health-tech-survey-r8hdtjdfj9wdbg6p5o9f7n.streamlit.app/)**

---

## 📌 Project Overview

Mental health is an important issue in the technology workplace. This project analyzes survey data to understand patterns related to mental health treatment, family history, workplace support, remote work, and other factors.

The project combines **Data Cleaning, Exploratory Data Analysis (EDA), and Streamlit Dashboard Development**.

---

## 🎯 Project Objectives

* Analyze the demographic characteristics of survey respondents.
* Understand the relationship between mental health treatment and family history.
* Analyze workplace factors related to mental health.
* Examine the relationship between remote work and treatment.
* Analyze the availability of mental health benefits and care options.
* Identify important patterns from the survey data.
* Build an interactive dashboard for exploring the results.

---

## 🧹 Data Cleaning & Preprocessing

The dataset was prepared before performing the analysis.

Main preprocessing steps included:

* Removed unnecessary `comments` data.
* Converted the `Timestamp` column into datetime format.
* Filtered unrealistic age values.
* Standardized gender categories.
* Handled missing values in relevant columns.
* Removed duplicate records.
* Prepared the cleaned dataset for analysis.

## ⚙️ How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/anandabhi985-del/mental-health-tech-survey
```

### 2. Move into the project directory

```bash
cd Mental-Health-Tech-Survey
```

### 3. Install the required libraries

```bash
pip install -r requirements.txt
```

### 4. Run the Streamlit application

```bash
streamlit run app.py
```

The dashboard will open in your browser.
